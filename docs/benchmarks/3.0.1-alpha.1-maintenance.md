## Assessment and limits

Frame handling reduces measured synchronous work while preserving map node identity and
eliminating unnecessary reconstruction. This is the specific improvement, not a global
speed claim. The full tables deliberately retain slower Lock updates, initial mounts and
some lifecycle/metadata profiles: persistent reconciliation and finite state feedback have
bookkeeping costs. Compare absolute workload costs before interpreting large percentages
on small baselines. The audit removed redundant reconciliation of freshly cloned nodes
after an earlier diagnostic exposed initial-mount overhead; these samples use the final
optimized source only.

Gestures are native browser event fixtures, not physical fingers. iPhone WebKit is emulation,
not a real iPhone. Real Roborock frame/network latency, native mobile compositor smoothness
and lower-powered devices remain field-validation limits. No public API, YAML, service
behavior, dependency or global cache is added. Published stable assets and historical
benchmark data remain unchanged.

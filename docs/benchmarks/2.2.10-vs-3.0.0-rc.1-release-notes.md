## Performance vs Nodalia Cards 2.2.10

Reference: Apple M4, darwin arm64, Chromium 153.0.8010.12. Values are medians from 7 samples; browsers are not averaged.

Measured the exact published 3.0.0-rc.1 asset. [Full three-engine RC report](https://github.com/danielmigueltejedor/nodalia-cards/blob/main/docs/benchmarks/2.2.10-vs-3.0.0-rc.1.md) · [Raw samples and hashes](https://github.com/danielmigueltejedor/nodalia-cards/blob/main/docs/benchmarks/2.2.10-vs-3.0.0-rc.1.json).

Firefox performance is unavailable on this reference Mac and explicitly excluded by the release owner for RC acceptance. Linux Firefox compatibility tests remain required. This exception cannot generate stable 3.0.0 evidence.

| Fresh-context module load (ms) | 66.60 | 46.50 | -30.2% |

| Unrelated HA updates, synchronous work (ms) | 58.30 | 69.60 | 19.4% |

These fixture measurements describe specific operations on the reference machine, not a global speed increase. Heap deltas alone do not establish a leak. See p95, engine differences, workload definitions and limitations in the full report.
